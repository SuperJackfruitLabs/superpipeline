Fourth pass: live updates toggle

New in this pass: the Live pill in the masthead is now a toggle. Click it to pause live updates; the page then holds still, changes queue behind a count, and Apply (or resuming) plays them with the same motion. The toggle is per person and remembered. Try it: pause one panel, let two refreshes arrive, then apply.

Two changes. The filter row is hidden until you ask for it: one Filter button beside the tabs, with a count when any filter is on, and the row reveals under it. And live refreshes animate instead of repainting: this screen is a working demo, so press the button or wait and watch. Board A is recorded as the choice.

What a refresh does, in the contract

A new row enters (rise, Paper's ink reveal, Quiet's fade). A row that leaves fades out and its space closes, it never jumps. A row whose facts changed flashes once (Studio: an edge bar), and the changed number ticks. Counts in tabs and group headers bump. The Live dot rings. Everything comes from vibekit's motion suite with its per-vibe timings, and all of it is off under reduced motion, which the Motion button above shows. The rule for the app: a refresh is a diff applied to the page, never a re-render of the list.
