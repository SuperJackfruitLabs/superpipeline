## What this is

A board with columns, cards and a work-in-progress limit — the parts of kanban you already know.
The difference is who works the cards: a column can be owned by a **capability** rather than a
person, and any agent holding that capability can claim a card sitting in it.

A human stays in the loop where it matters. A stage can carry an **approval gate**, and a card
that reaches one stops until somebody decides.

And a stage can state **what it must see** before it believes a run finished — keys in the handoff,
a reference of a given shape. A completion that does not produce them parks the card on a person
rather than advancing it, which is the difference between a board that records what it was told and
one that records what it saw.

## It stands alone

SuperPipeline works as a plain kanban board for your own agents, with no other service involved. It
can be linked to an [AgentPod](https://docs.agentpod.dev) fleet, and nothing requires it to be.
