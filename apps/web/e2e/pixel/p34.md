### Task 34: New card composer and Move dialog, on a shared dialog frame

This lands the dialog groundwork that Tasks 35–37 reuse, and two dialogs on it. The groundwork is `DialogFrame`, the REF-markup `Segmented`, `Icon`, the hand-written layer CSS, and a root-scoped mode for `extract-css.mjs`. The two dialogs are the new card composer (`SP-Dlg-NewCard-{Daylight,Paper,Studio,Quiet}`) and the Move dialog (`SP-Dlg-Move-*`). Both turn green in light and dark. Rulings applied:
- D-1 out of scope: the composer has no draft button, no "drafted" note and no brief tag. The NewCard `refPatch` deletes `.nc-draftrow` and `.nc-brief-tag` from the reference. The follow-up note `docs/follow-ups/agent-drafted-new-card.md` records what drafting needs.
- `createCard` takes `stageKey`/`labelIds`/`projectId` (Task 10).
- The LabelPicker's Escape stops propagation, so the harness's final Escape closes only the picker.
- Dialogs are compared by `parts` = `section.dlg`, and the harness blurs after the steps.
- The Move owner face uses the reference's mood rule. The moved card's last agent shows its mood, and every other sole owner shows `resting`.

**How the reference CSS is ported for every dialog (Tasks 34–37).** In each dialog reference, all rules sit under `:where(.fg)`. Every vibe file also carries the mockup's own vibe-neutral `vk-button`/`vk-segmented`/`vk-field` rules, and these differ from vibekit 0.1.0's per-vibe forms. So each dialog's four vibe files are extracted separately. Each file is re-rooted under `.fg[data-dlg="<id>"][data-vibe="<vibe>"]`, with those vk rules scoped under the same root. The app's dialog layer is a real `div.fg` that carries `data-dlg`, `data-vibe`, `data-theme` (and `data-accent` for Appearance). Two consequences:
- The reference CSS applies verbatim, one vibe at a time, including per-vibe positions such as `.bs` left/top and the toast top.
- Every rule gains the same `(0,2,0)`, so the reference's internal cascade is unchanged and the ported rules beat vibekit 0.1.0's global component rules inside dialogs only.

The artboard's absolute `left/top` is undone by one hand-written layer delta (`dialog-layer.css`, spec dialogs.md §0.3).

//   --with also keeps the reference's own (mockup vk.css) rules for those class prefixes, each selector

import { dirname, join } from 'node:path';
import { fileURLToPath } from 'node:url';

const here = dirname(fileURLToPath(import.meta.url));
const [artboard, ...rest] = process.argv.slice(2);

const list = (k) => (arg(k) ?? '').split(',').filter(Boolean);
const prefixes = list('--prefix');
const root = arg('--root');
const as = arg('--as');

const usage = 'usage: extract-css.mjs <Artboard> (--prefix a-,b- | --root <text> [--as <selector>] [--with vk-a,vk-b]) [--out file]';
if (!artboard || (prefixes.length === 0 && !root)) { console.error(usage); process.exit(2); }
if (withs.length && (!root || !as)) { console.error('--with needs --root and --as'); process.exit(2); }

/** Split top-level CSS into [prelude, body] blocks, keeping @media/@supports/@container groups. */
function blocks(src) {
  const out = []; let depth = 0, start = 0, open = -1;
  for (let i = 0; i < src.length; i++) {
    const c = src[i];
    if (c === '/' && src[i + 1] === '*') { const e = src.indexOf('*/', i + 2); i = e < 0 ? src.length : e + 1; continue; }
    if (c === '{') { if (depth === 0) open = i; depth++; }
    else if (c === '}') { depth--; if (depth === 0) { out.push([src.slice(start, open).trim(), src.slice(open + 1, i)]); start = i + 1; } }
  }
  return out;
}
/** A selector list split on its top-level commas (not those inside :is(), [attr] or :where()). */
function parts(sel) {
  const out = []; let depth = 0, cur = '';
  for (const ch of sel) {
    if (ch === '(' || ch === '[') depth++;
    else if (ch === ')' || ch === ']') depth--;
    if (ch === ',' && depth === 0) { out.push(cur.trim()); cur = ''; } else cur += ch;
  }
  if (cur.trim()) out.push(cur.trim());
  return out;
}
const mentions = (sel, ps) => ps.some((p) => new RegExp(`\\.${p.replace(/[-]/g, '\\-')}`).test(sel));

/** The selector to write for a rule, or null to drop it. */
function select(sel) {
  if (/\.sc-/.test(sel)) return null;
  if (root) {
    if (sel.includes(root)) return as ? sel.split(root).join(as) : sel;
    if (withs.length && !sel.includes(':where(.backdrop)') && mentions(sel, withs)) return parts(sel).map((s) => `${as} ${s}`).join(', ');
    return null;
  }
  return mentions(sel, prefixes) ? sel : null;
}

const kept = [];
const frames = [];
for (const [prelude, body] of blocks(css)) {
  if (/^@(media|supports|container)/.test(prelude)) {
    const inner = blocks(body).map(([s, b]) => [select(s), b]).filter(([s]) => s).map(([s, b]) => `  ${s} {${b}}`);
    if (inner.length) kept.push(`${prelude} {\n${inner.join('\n')}\n}`);
  } else if (/^@keyframes/.test(prelude)) {
    frames.push([prelude, body]);
  } else {
    const s = select(prelude);
    if (s) kept.push(`${s} {${body}}`);
  }
}
// A keyframes block is global, so it comes along only when a kept rule animates with it (or, in
// prefix mode, when its own name carries a prefix, as before).
const animated = new Set([...kept.join('\n').matchAll(/animation(?:-name)?\s*:\s*([^;}]+)/g)].flatMap((m) => m[1].split(/[\s,]+/)));

  if (animated.has(name) || (!root && prefixes.some((p) => prelude.includes(p)))) kept.push(`${prelude} {${body}}`);
}

/**
 * Who picks a card up in a stage, as the new-card composer and the Move dialog say it. Built on
 * `stageOwner()`: it reports who DECLARES a capability, never who can claim it.
 */
import type { AgentSummary, Stage } from '$lib/api';
import { stageOwner } from '$lib/components/board/stage-owner';

function requirement(stage: Stage): { caps: string[]; mode: 'all' | 'any' } {
  if (stage.requires?.all?.length) return { caps: stage.requires.all, mode: 'all' };
  if (stage.requires?.any?.length) return { caps: stage.requires.any, mode: 'any' };
  return { caps: stage.owner ? [stage.owner] : [], mode: 'any' };
}

/** "integration, api or testing" (any) · "code and review" (all). */
export function joinCaps(caps: string[], mode: 'all' | 'any'): string {
  if (caps.length <= 1) return caps.join('');
  return `${caps.slice(0, -1).join(', ')}${mode === 'all' ? ' and ' : ' or '}${caps[caps.length - 1]}`;
}

/** The one agent that alone works this stage: a stage pinned to an agent, or a capability one agent declares. */
export function soleAgent(stage: Stage, agents: AgentSummary[]): AgentSummary | null {
  if (stage.ownerKind === 'agent') return agents.find((a) => a.id === stage.owner) ?? null;
  const o = stageOwner(stage, agents);
  if (o.kind !== 'capability' || o.declaredBy.length !== 1) return null;
  return agents.find((a) => a.name === o.declaredBy[0]) ?? null;
}

/** The stage picker's option suffix: "a person", "approval gate", "error-eric", "2 agents". */
export function ownerShort(stage: Stage, agents: AgentSummary[]): string {
  const o = stageOwner(stage, agents);
  if (o.kind === 'human') return stage.gate === 'approval' ? 'approval gate' : 'a person';
  if (o.kind === 'agent') return o.label;
  const n = o.declaredBy.length;
  return n === 0 ? 'no agent yet' : n === 1 ? o.declaredBy[0]! : `${n} agents`;
}

/** The Move row's owner line: "diagnostics · error-eric", "code · 2 agents", "a person · approval". */
export function ownerLine(stage: Stage, agents: AgentSummary[]): string {
  const o = stageOwner(stage, agents);
  if (o.kind !== 'capability') return o.label;
  const n = o.declaredBy.length;
  return `${o.label} · ${n === 0 ? 'no agent yet' : n === 1 ? o.declaredBy[0] : `${n} agents`}`;
}

/** What happens to a card that lands here (D-13). */
export function pickupSentence(stage: Stage, stages: Stage[], agents: AgentSummary[]): string {
  const o = stageOwner(stage, agents);
  if (o.kind === 'human') {
    if (stage.gate === 'approval') return 'It waits here for a person to approve before it can ship.';
    const last = [...stages].sort((a, b) => a.order - b.order).at(-1);
    return last?.key === stage.key ? 'It lands with the finished work.' : 'A person picks it up here; no agent works this stage.';
  }
  if (o.kind === 'agent') return `${o.label} picks it up.`;
  const n = o.declaredBy.length;
  if (n === 0) return `No agent declares ${o.label} yet, so it waits here.`;
  if (n === 1) return `${o.declaredBy[0]} picks it up.`;
  const r = requirement(stage);
  return `One of the ${n} agents with ${joinCaps(r.caps, r.mode)} picks it up.`;
}

/** The composer foot, split so the stage name can be <strong>. */
export function dispatchFoot(stage: Stage, boardName: string, agents: AgentSummary[]): { before: string; stage: string; after: string } {
  const o = stageOwner(stage, agents);
  let where: string;
  if (o.kind === 'human') where = stage.gate === 'approval' ? 'a person approves it.' : 'a person picks it up.';
  else if (o.kind === 'agent') where = `${o.label} picks it up.`;
  else if (o.declaredBy.length === 0) where = `it waits: no agent declares ${o.label} yet.`;
  else if (o.declaredBy.length === 1) where = `${o.declaredBy[0]} picks it up.`;
  else { const r = requirement(stage); where = `one of the ${o.declaredBy.length} agents with ${joinCaps(r.caps, r.mode)} picks it up.`; }
  return { before: 'Goes to ', stage: stage.name, after: ` on ${boardName}, where ${where}` };
}

    open: boolean;

    role?: 'dialog' | 'alertdialog';
    labelledby?: string;
    describedby?: string;
    label?: string;
    width: number;
    top: number;
    onClose?: () => void;
    onkeydown?: (e: KeyboardEvent) => void;
    initialFocus?: string;
    accent?: boolean;
    z?: number;
    box?: { left: number; top: number } | null;
    before?: Snippet;
    children: Snippet;

  let panel = $state<HTMLElement | null>(null);
  const FOCUSABLE = 'a[href],button:not([disabled]),input:not([disabled]),select:not([disabled]),textarea:not([disabled]),summary,[tabindex]';

  /** The Tab order: a native radio group is one stop (its checked member, else its first). */
  function tabStops(): HTMLElement[] {
    if (!panel) return [];
    const seen = new Set<string>();
    const out: HTMLElement[] = [];
    for (const el of panel.querySelectorAll<HTMLElement>(FOCUSABLE)) {
      if (el.tabIndex < 0) continue;
      if (el instanceof HTMLInputElement && el.type === 'radio') {
        if (seen.has(el.name)) continue;
        seen.add(el.name);
        out.push(panel.querySelector<HTMLElement>(`input[type="radio"][name="${el.name}"]:checked:not([disabled])`) ?? el);
      } else out.push(el);
    }
    return out;
  }

  $effect(() => {
    if (!open) return;
    const opener = document.activeElement as HTMLElement | null;
    openFrames += 1;
    document.querySelector('.app-root')?.setAttribute('inert', '');
    void tick().then(() => {
      const first = (initialFocus ? panel?.querySelector<HTMLElement>(initialFocus) : null) ?? tabStops()[0] ?? panel;
      first?.focus();
    });
    return () => {
      openFrames -= 1;
      if (openFrames === 0) document.querySelector('.app-root')?.removeAttribute('inert');
      if (opener && document.contains(opener)) opener.focus();
    };
  });

  function keydown(e: KeyboardEvent): void {
    onkeydown?.(e);
    if (e.defaultPrevented) return;
    if (e.key === 'Escape') {
      // Stopped even without onClose: Escape behind a dialog must not also close the card drawer.
      e.preventDefault();
      e.stopPropagation();
      onClose?.();
      return;
    }
    if (e.key !== 'Tab') return;
    const f = tabStops();
    if (f.length === 0) { e.preventDefault(); return; }
    const first = f[0]!, last = f[f.length - 1]!;
    const here = document.activeElement;
    if (e.shiftKey && (here === first || here === panel)) { e.preventDefault(); last.focus(); }
    else if (!e.shiftKey && here === last) { e.preventDefault(); first.focus(); }
  }
</script>

# Follow-up: an agent drafts the new card (dialogs D-1)

The vibes sweep shipped the new card composer without drafting. The person writes the title and the
brief. The SP-Dlg-NewCard references draw the drafted state: a "Draft again" button and the note
"**super-chotu** drafted the title and brief from your sentence. Change anything.", plus a
"Drafted · not sent yet" tag on the brief. The pixel harness deletes `.nc-draftrow` and
`.nc-brief-tag` from those references until this lands. The composer's lead copy already promises
drafting ("An agent drafts the brief…"), so this is the gap between the copy and the product.

## What it needs

**API (apps/api)**
- `POST /v1/boards/:boardId/drafts` `{ sentence }` → `202 { draft: { id, status: 'drafting', drafter: { agentId, name } } }`.
  The drafter is the board's command agent: the agent holding the `command` capability that may
  dispatch on this board. If there is none, `409 { error: { code: 'NO_DRAFTER' } }`.
- `GET /v1/drafts/:id` → `{ draft: { id, status: 'drafting' | 'ready' | 'failed', sentence, title?, brief?, drafter } }`.
- `PUT /v1/drafts/:id` (agent-authenticated) `{ title, brief }` sets `status: 'ready'`. A draft is
  never a card. It is discarded on dispatch or after 24h.
- A board socket event `draft.ready` `{ draftId }` to the person who asked, so the composer updates
  without polling.

**MCP (agents)**
- Tool `draft_card` `{ draftId, title, brief }`, the drafter's write path. The drafter learns of a
  request through its normal dispatch, as a draft task. It must not create a card.

**Web (apps/web)**
- `api.ts`: `requestDraft(boardId, sentence)`, `getDraft(id)`.
- `NewCardDialog.svelte`: the `.nc-draftrow` button ("Draft brief", then "Draft again" once
  drafted), with the sparkle icon. States:
  - "Drafting…" (disabled);
